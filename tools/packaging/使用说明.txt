QCY H3 耳机托盘控制工具（QcyH3Tray）
========================================

【快速开始（便携版）】
1. 将本压缩包完整解压到任意目录（建议先解压再运行，不要直接在压缩包内双击）。
2. 双击 QcyH3Tray.App.exe 启动。程序常驻系统托盘（屏幕右下角耳机小图标），不弹主窗口。
3. 首次启动会弹出设备选择窗口：
   - 先在手机 QCY App 上断开耳机连接（耳机同时只能被一台设备占用）；
   - 保持耳机开机、未放入充电盒、在电脑蓝牙有效范围内；
   - 在窗口中选择你的 QCY H3 设备，点击连接。
   之后每次启动会自动连接记住的设备。

【SmartScreen 提示处理】
首次运行如出现"Windows 已保护你的电脑"蓝色提示：
1. 点击「更多信息」；
2. 点击「仍要运行」。
本程序未做代码签名（个人开源项目），提示属正常现象；源码见项目 GitHub 仓库。

【日常使用】
- 左键点击托盘图标：打开/收起快捷面板（电量、降噪、均衡器、游戏模式）。
- 右键点击托盘图标：打开控制中心 / 立即重连 / 开机自启 / 退出。
- 控制中心可设置：通知开关、低电量提醒阈值、自动关机、按键自定义等。
- 关闭面板与控制中心窗口只是最小化到托盘；退出请用托盘右键菜单「退出」。

【常见问题】
1. 提示"蓝牙不可用"：检查电脑蓝牙是否开启；蓝牙恢复后程序会自动重连，无需手动干预。
2. 一直显示"耳机不可达 / 重连中"：确认耳机已开机、未入盒、未超出范围，并且已与手机
   QCY App 断开（耳机同一时间只能被一台设备占用）。
3. 刚断开后立即重连失败：Windows 对刚断开的蓝牙链路有几秒访问冷却，程序会自动退避
   重试（2 秒 / 5 秒 / 30 秒），稍等即可，不要频繁手动重试。

【运行要求】
- Windows 10（19041 及以上）/ Windows 11；
- 便携版自带 .NET 8 运行时；安装版（setup）需要 .NET 8 Desktop Runtime x64。
