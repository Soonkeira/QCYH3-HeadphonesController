QCY H3 耳机托盘控制工具（安装版 / setup）
========================================

【安装前须知】
- 本包为"框架依赖"版本，需要已安装 .NET 8 Desktop Runtime（x64）。
  未安装请先到 https://dotnet.microsoft.com/download/dotnet/8.0 下载
  "Desktop Runtime 8.0.x → Windows x64" 安装。
  不想安装运行时？请使用 portable 便携版（自带运行时，解压即用）。

【安装步骤】
1. 将本压缩包完整解压到任意临时目录。
2. 打开 PowerShell（开始菜单搜索"PowerShell"），执行：
       cd 解压目录
       powershell -ExecutionPolicy Bypass -File .\install.ps1
   可选参数：
       .\install.ps1 -Autostart      同时注册开机自启（当前用户 HKCU Run 键）
       .\install.ps1 -WhatIf         干跑预览，不做任何更改
3. 安装内容（全部仅限当前用户，无需管理员权限）：
   - 程序文件复制到 %LOCALAPPDATA%\Programs\QcyH3Tray；
   - 开始菜单快捷方式「QCY H3 控制中心」；
   - （使用 -Autostart 时）开机自启注册表项。
4. 启动：开始菜单「QCY H3 控制中心」，或直接运行安装目录中的 QcyH3Tray.App.exe。
   日常使用与常见问题见压缩包内《使用说明.txt》。

【SmartScreen / 执行策略提示】
- 直接运行 .ps1 弹出记事本属正常（系统默认不允许双击运行脚本），请按上面步骤 2 用命令行执行，
  或右键 install.ps1 →「使用 PowerShell 运行」。
- 出现"Windows 已保护你的电脑"：点击「更多信息」→「仍要运行」。
- 出现"在此系统上禁止运行脚本"：请使用步骤 2 的完整命令（-ExecutionPolicy Bypass 只对当次进程生效）。

【首次连接引导】
耳机如已连接手机 QCY App，请先在手机端断开（耳机同时只能被一台设备占用），
保持耳机开机，首次启动后在设备选择窗口中选择你的 QCY H3。

【卸载】
在安装目录（或解压目录）执行：
       powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
       .\uninstall.ps1 -KeepConfig      保留用户配置（设备记忆、通知与 EQ 设置）
卸载会清理：运行中的实例、开始菜单快捷方式、开机自启注册表项、用户配置（默认删除）、程序目录。
